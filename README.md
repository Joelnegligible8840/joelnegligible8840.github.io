# Інформатика та ШІ — збірник ресурсів

GitHub-ready копія сайту для перенесення в окремий репозиторій.

## Що входить

- `artifacts/edtech-resources/` — React + Vite сайт, усі сторінки та адмін-форма `/admin`;
- `artifacts/api-server/` — Express API для ресурсів, категорій, тегів і статистики;
- `lib/db/` — схема PostgreSQL та робота з Drizzle;
- `lib/api-spec/` і `lib/api-client-react/` — OpenAPI-специфікація та згенеровані клієнтські хуки;
- `data/resources.json` — повний каталог із 109 ресурсами;
- `data/resources.csv` — каталог у табличному форматі;
- `attached_assets/` — банер та завантажені матеріали;
- `pnpm-lock.yaml` — зафіксовані версії залежностей.

Зовнішні освітні матеріали не копіюються фізично: у каталозі збережені їхні назви, описи, категорії, теги та оригінальні URL.

## Запуск локально

Потрібні Node.js 20+ і pnpm.

```bash
pnpm install
```

Потрібна змінна середовища `DATABASE_URL` із доступом до PostgreSQL.

В окремих терміналах запустіть API та сайт:

```bash
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/edtech-resources run dev
```

Після запуску відкрийте адресу фронтенду, яку покаже Vite. Для додавання ресурсів перейдіть на `/admin`.

## Перенесення в GitHub

1. Створіть порожній GitHub-репозиторій.
2. Завантажте в нього весь вміст цієї папки.
3. Не додавайте секрети або реальний `DATABASE_URL` у файли репозиторію.
4. Налаштуйте `DATABASE_URL` у середовищі хостингу.
5. Запустіть `pnpm install`, а потім команди запуску API та фронтенду.
